# Opening popup image

Drop one image in this folder to show it at the top of the opening popup
(the language picker / schedule popup).

- Name it **`cover.png`** (or `.jpg`, `.jpeg`, `.webp`).
- If no `cover.*` is found, the popup will also look for **`01.png`**.
- If neither exists, the popup simply shows no image.

Recommended: a portrait or square image; it is scaled to fit and capped at
about 38% of the screen height.
