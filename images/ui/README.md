# Hand-drawn UI artwork

Drop your drawings here (PNG with a transparent background works best, or SVG).
The site references these exact filenames:

| File                      | Where it's used                                  |
|---------------------------|--------------------------------------------------|
| `language.png`            | centre image on the language-select page         |
| `vase.png`                | the big vase silhouette on the main page         |
| `episodes.png`            | the flower button (= episodes) on the main page  |
| `muratypes.png`           | the framed-squares button (= 무라체) on the main page |
| `signature.png`           | the signature at the bottom of the main page     |
| `mura.png` (optional)     | the "mura" wordmark, top-left of the main page    |

Notes
- Transparent PNGs sit cleanly on the jade background.
- If a file is missing, the site falls back to text so nothing breaks.
- Tell me if you'd rather use different names and I'll point the code at them.
