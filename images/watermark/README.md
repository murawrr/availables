# Watermark logo

Drop your logo here so it appears on the menu pages (home + availables), in the
space between the menu bars and the footer.

## How to use

1. Add your logo image to this folder named **`logo.png`**
   (path: `images/watermark/logo.png`).
2. That's it — it will show up automatically.

### Notes

- A transparent PNG works best.
- To use a different filename or format (e.g. `logo.svg`), update
  `WATERMARK_SRC` near the top of `script.js`.
- If no `logo.png` is present, nothing is shown (no broken image).
- Display size is capped at ~260px wide; adjust `.site-watermark img` in
  `style.css` if you want it larger or smaller.
